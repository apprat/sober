# Scrollbar

滚动条，v2 版本中滚动条组件已被移除，请使用引入样式替代

```js
//使用构建工具（推荐）
import 'sober/styles/scrollbar.css'
```

直接在浏览器中引入。

```html
<!-- 直接在浏览器中引入-->
<link rel="stylesheet" href="https://unpkg.com/sober/style/table.css">
```

它会为所有元素添加滚动条样式（仅支持鼠标的设备）。
