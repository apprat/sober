# text-field

```html preview
<s-text-field placeholder="请输入内容"></s-text-field>
```

使用 `label` 插槽显示浮动标签

```html preview
<s-text-field>
  <div slot="label">请输入文本</div>
</s-text-field>
<s-text-field>
  <div slot="label"></div>
</s-text-field>
```

多行文本输入框

```html preview
<s-text-field type="multiline">
  <div slot="label">请输入文本</div>
</s-text-field>
```
